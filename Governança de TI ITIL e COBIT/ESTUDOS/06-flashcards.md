# Governança de TI — Flashcards

| Pergunta | Resposta |
|---|---|
| Foco da gestão? | Operar e executar. |
| Foco da governança? | Direcionar, monitorar e avaliar. |
| Pergunta da gestão? | Estamos fazendo as coisas do jeito certo? |
| Pergunta da governança? | Estamos fazendo as coisas certas? |
| Responsáveis pela governança? | Diretoria (board), executivos, CIO. |
| Governança habilita o quê? | Alinhamento negócio/TI → valor de negócio. |
| ITIL significa? | Information Technology Infrastructure Library. |
| COBIT significa? | Control Objectives for Information and Related Technologies. |
| Quem criou o ITIL e quando? | CCTA (governo britânico), 1989. |
| Quem criou o COBIT e quando? | ISACA, 1996. |
| COBIT nasceu para quê? | Auditar e controlar riscos de TI. |
| Dono atual do ITIL? | PeopleCert (desde 2021). |
| Axelos? | Joint venture governo britânico + Capita (2013). |
| ITIL v3? | Ciclo de vida do serviço, 26 processos (2007/2011). |
| ITIL 4? | SVS, 34 práticas, ágil (2019). |
| ITIL 5? | 2026, ciclo de vida do produto e governança de IA. |
| COBIT 5 (2012)? | Integração: Val IT, Risk IT, ITAF; coordena com ITIL e ISO. |
| COBIT 2019? | Fatores de design (governança customizada). |
| COBIT = o quê/como? | O QUÊ (painel/GPS). |
| ITIL = o quê/como? | COMO (motor). |
| 5 componentes do SVS? | Princípios, Governança, Cadeia de valor, Práticas, Melhoria contínua. |
| Governança no SVS? | Avaliar, Direcionar, Monitorar. |
| 7 princípios? | Focar em valor; Começar de onde está; Iterar com feedback; Colaborar e dar visibilidade; Holístico; Simples e prático; Otimizar e automatizar. |
| Otimizar ou automatizar primeiro? | Otimizar. |
| Princípios são...? | A bússola: como decidir. |
| Práticas são...? | A ferramenta: o que fazer. |
| 6 atividades da cadeia? | Planejar, Melhorar, Engajar, Desenhar e Transicionar, Obter/Construir, Entregar e Suportar. |
| Cadeia × fluxo de valor? | 6 blocos universais × combinação para uma demanda. |
| Atividades × práticas? | O QUE (6) × COMO (34). |
| 4 dimensões? | Organizações e pessoas; Informação e tecnologia; Parceiros e fornecedores; Fluxos de valor e processos. |
| Fórmula do valor? | Utilidade + Garantia − Custos & Riscos. |
| Utilidade? | Adequado ao propósito: o que o serviço faz. |
| Garantia? | Adequado ao uso: como o serviço performa. |
| 34 práticas divididas em? | 14 gerais, 17 de serviço, 3 técnicas. |
| Incidente? | Interrupção não planejada; restaurar rápido. |
| Solicitação? | Pedido padrão, rotineiro, não é falha. |
| Problema? | Causa raiz de incidentes; evitar recorrência. |
| Service Desk? | Canal principal com o usuário; acolhe, classifica, informa. |
| Métrica do incidente? | Velocidade de restauração. |
| Restaurar = eliminar causa? | Não. |
| Caso Oxford? | Incidentes graves 8 → 2 por ano com princípios. |
| Caso Disney? | 20 champions internos no ITIL v3. |
| Caso BNA? | COBIT 2019 top-down, equipe interna, 300+ melhorias. |
| 7 componentes do COBIT (BNA)? | Processos, Pessoas, Estruturas, Fluxos, Políticas, Cultura, Infraestrutura. |
| ITIL Foundation? | 60 min, 40 questões, 65% (26 acertos). |
