# Auditoria de Segurança da Informação — Flashcards

| Pergunta | Resposta |
|---|---|
| O que é auditoria? | Exame de operações, processos, sistemas e responsabilidades para verificar conformidade com políticas, regras e normas. |
| O que é auditoria de sistemas? | Avaliação dos controles internos de sistemas computacionais. |
| O que a auditoria de sistemas assegura? | Integridade, confiabilidade, segurança e conformidade. |
| Foco da auditoria contábil? | Registros financeiros. |
| Foco da auditoria de sistemas? | Controles, acessos, segurança e operação de TI. |
| 5 tipos de auditoria? | Interna, Externa, Operacional, De Conformidade, De Sistemas. |
| 6 etapas do ciclo? | Planejamento, Execução, Coleta de Evidências, Análise, Relatório, Acompanhamento. |
| Última etapa do ciclo? | Acompanhamento. |
| 4 objetivos da auditoria de sistemas? | Avaliar controles, garantir segurança, identificar vulnerabilidades, promover conformidade. |
| Importância da auditoria? | Protege ativos, previne fraudes, apoia governança de TI, atende leis/normas. |
| O que é Segurança da Informação? | Proteção contra acessos não autorizados garantindo C-I-D. |
| Confidencialidade? | Proteção contra acesso indevido. |
| Integridade? | Informação não alterada indevidamente. |
| Disponibilidade? | Acesso garantido quando necessário. |
| DDoS ataca qual princípio? | Disponibilidade. |
| 5 ameaças da aula? | Malware, Phishing, DDoS, Engenharia social, Ransomware. |
| O que é vulnerabilidade? | Fragilidade em sistema/processo que pode ser explorada por ameaças. |
| 4 exemplos de vulnerabilidade? | Software desatualizado, senha fraca, falta de backup, permissões mal configuradas. |
| 5 medidas de proteção? | Antivírus/firewall, criptografia, controle de acesso, atualizações, políticas de segurança. |
| Segurança no ciclo de vida: etapas? | Análise de riscos, testes de segurança, monitoramento contínuo, descarte seguro. |
| Escopo da auditoria de SI? | Política de segurança, acesso lógico, acesso físico, controles ambientais, contingência/continuidade. |
| Auditoria de aplicativos foca em? | Um aplicativo: desenvolvimento, entrada/processamento/saída, conteúdo. |
| Proteção da informação tem quais 2 lados? | Física e lógica. |
| Auditoria (contexto) testa o quê? | Confiabilidade dos registros com base nos documentos-fonte. |
