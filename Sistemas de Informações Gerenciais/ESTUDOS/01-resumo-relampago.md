# Sistemas de Informações Gerenciais — Resumo Relâmpago

**Material na pasta:** 3 estudos de caso (17/08, 24/08 e 14/09/2026). **Não há slides de teoria**, cronograma nem data de prova.

## O que é a matéria
SIG estuda como **sistemas de informação** apoiam (ou atrapalham) a **gestão e a decisão** nas empresas. Os casos seguem o modelo do livro "Resolvendo problemas organizacionais" (estilo Laudon — complemento): todo problema tem **3 dimensões**: **Pessoas, Organização e Tecnologia**.

## Os pontos que mais importam
1. **Método de análise de caso (complemento, é o que as perguntas pedem):** Problema → Causas → Impacto → Soluções possíveis → Solução escolhida → Implementação → Resultado.
2. **As 3 dimensões:** Humanas (pessoas, cultura, treinamento, resistência), Organizacionais (liderança, processos, estrutura, política), Tecnológicas (sistemas legados, integração, infraestrutura).
3. **Caso Reunião tumultuada (17/08):** falta de foco, culpa, política interna → problema **comportamental**. Solução: reunião com pauta, dados objetivos, papéis e plano de ação.
4. **Caso FBI – Virtual Case File (24/08):** 5 sistemas isolados, papel, cultura sigilosa, 14 gerentes e 4 CIOs, 1,3 mudança/dia, sem testes → **US$ 170 mi** e projeto abandonado (2005). Substituto: **Sentinel** (80–90% software de prateleira).
5. **Caso Comair (14/09):** sistema legado **SBS** (Fortran, 11+ anos) com limite de **32.768 mudanças/mês** → colapso em **25/12/2004**, 1.100 voos cancelados, **US$ 20 mi** de prejuízo. Substituição adiada por anos (falta de liderança em TI, aquisição pela Delta, greve, 11/09).
6. **Lições comuns:** sistema legado é risco · integração de dados é essencial · **liderança e governança** de TI pesam mais que tecnologia · requisitos que mudam demais matam projetos · sempre ter **contingência/backup**.

## Como tudo se conecta
```
PROBLEMA (sintoma) ──► CAUSAS em 3 dimensões
                          ├─ Pessoas
                          ├─ Organização
                          └─ Tecnologia
                     ──► IMPACTO (dinheiro, imagem, segurança)
                     ──► SOLUÇÕES (alternativas + escolha justificada)
                     ──► IMPLEMENTAÇÃO (considerar as 3 dimensões de novo)
```

## Estilo do professor
Questões **dissertativas de estudo de caso**, sempre "descreva o problema, causas, impacto, soluções e aspectos humanos/organizacionais/tecnológicos". Responda **em tópicos pelas 3 dimensões**.
