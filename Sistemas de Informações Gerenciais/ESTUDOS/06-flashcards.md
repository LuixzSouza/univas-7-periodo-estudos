# Sistemas de Informações Gerenciais — Flashcards

| Pergunta | Resposta |
|---|---|
| 3 dimensões de um problema de SI? | Pessoas, Organização, Tecnologia. |
| Modelo de resposta de caso? | Problema → Causas → Impacto → Soluções → Escolha → Implantação. |
| Reunião tumultuada: vendas abaixo quanto? | 30% abaixo do planejado. |
| Tema que deveria ser discutido? | "O que fazer para aumentar as vendas?" |
| Tipo de problema da reunião? | Comportamental/organizacional. |
| FBI: projeto de modernização? | Trilogy (2000), US$ 379 mi. |
| VCF significa? | Virtual Case File (Arquivo de Caso Virtual). |
| Quem desenvolveu o VCF? | SAIC. |
| Quantos bancos o VCF integraria? | 180. |
| Quanto o FBI gastou no VCF? | US$ 170 mi, só 1/10 pronto. |
| Quando o VCF foi abandonado? | 8 de março de 2005. |
| Substituto do VCF? | Sentinel (80–90% software de prateleira). |
| Quantos CIOs e gerentes no projeto? | 4 CIOs e 14 gerentes. |
| Pedidos de mudança no VCF? | ~1,3 por dia; contrato revisto 26 vezes. |
| O que deu certo no Trilogy? | Hardware, rede de 622 escritórios, Data Warehouse Investigativo (47 fontes). |
| Comair: sistema legado? | SBS, em Fortran, rodando em IBM AIX. |
| Limite do SBS? | 32.768 mudanças de escala por mês. |
| Data do colapso? | 25/12/2004. |
| Impacto na Comair? | 1.100 voos cancelados, US$ 20 mi, 30 mil passageiros. |
| Sistema escolhido para substituir? | SABRE AirCrews Operations Manager. |
| Por que a troca atrasou? | Vácuo de liderança em TI, aquisição pela Delta, greve, 11/09, custo. |
| Correção provisória da Comair? | Dividir o SBS em 2 módulos e monitorar volume. |
| Lição comum FBI e Comair? | Legado + falta de liderança/contingência = desastre. |
