# Gestão de Custos — Flashcards

| Pergunta | Resposta |
|---|---|
| Custo? | Gasto relativo à produção ("sacrifício na produção"). |
| Despesa? | Gasto com administração, vendas e financiamento. |
| Regra custo × despesa? | Até o produto ficar pronto para venda = custo; depois = despesa. |
| Custo direto? | Tem medida de consumo (kg, horas); não precisa de rateio. |
| Custo indireto? | Precisa de rateio (aluguel, supervisão, energia). |
| Custo fixo? | Não varia com o volume (aluguel da fábrica). |
| Custo variável? | Varia com o volume (matéria-prima, embalagem). |
| Fórmula CMV? | EI + C − EF. |
| Fórmula CPV? | EI + (In + MOD + GGF) − EF. |
| Fórmula CSV? | Sin + (MO + GDS + GIS) − Sfi. |
| CMV × CPV × CSV? | Revenda × produção própria × serviço. |
| GGF inclui? | Aluguel, energia, depreciação, MOI. |
| MOD? | Mão de obra que trabalha diretamente no produto; mensurável. |
| MOI? | Apoio/supervisão (manutenção, limpeza); vai por rateio. |
| Horas legais de referência da MOD? | 220 horas/mês. |
| Ociosidade da MOD vira? | Custo indireto. |
| Custo/hora MOD? | (Salário + encargos + benefícios) ÷ horas trabalhadas. |
| Custo de transformação? | MOD + CIF (sem matéria-prima). |
| Outro nome do custo de transformação? | Custo de conversão. |
| Matéria-prima × insumo? | MP compõe o produto; insumo é tudo que é necessário (gás, água, máquina). |
| Insumos ligados a? | Terra, trabalho e capital. |
| Custo × custeio? | Custo = soma dos gastos; custeio = método de apuração. |
| Custeio por absorção? | Todos os custos de produção vão ao produto; despesas fora. |
| Outro nome do absorção? | Custeio integral. |
| 3 passos do absorção? | Separar custos/despesas → apropriar diretos → ratear indiretos. |
| Centro produtivo? | Onde se produz/gera receita (produção, vendas). |
| Centro não produtivo? | Financeiro, RH, jurídico (só despesas). |
| Taxa de rateio? | CIF ÷ total da base. |
| Base para óleo das máquinas? | Hora-máquina. |
| Base para manutenção? | Horas de manutenção (ou nº de ordens de serviço). |
| ABC significa? | Activity-Based Costing — custeio baseado em atividades. |
| Lema do ABC? | Foco nas atividades, não nos produtos. |
| Lógica do ABC? | Atividades consomem recursos; produtos consomem atividades. |
| Objetivo do ABC? | Reduzir distorções do rateio arbitrário. |
| Direcionador (driver)? | Transação que mede a quantidade de trabalho numa atividade. |
| Direcionador de recurso? | Custo → atividade (ex.: % de tempo). |
| Direcionador de atividade? | Atividade → produto (ex.: nº de lotes). |
| Custo unit. do direcionador? | Custo da atividade ÷ total do direcionador. |
| Qtd vendida (sem EI)? | Produzida − estoque final. |
