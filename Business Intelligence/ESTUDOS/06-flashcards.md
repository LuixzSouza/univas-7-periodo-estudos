# Business Intelligence — Flashcards

| Pergunta | Resposta |
|---|---|
| Quem citou "BI" pela 1ª vez? | Hans Peter Luhn, IBM, anos 1950. |
| Definição de BI de Dresner? | Conceitos e métodos para melhorar decisões usando sistemas baseados em fatos. |
| O que é Business Analytics? | Leitura dos dados no contexto + ferramentas para interpretá-los. |
| Componente mais importante do BA? | Os dados. |
| O que é dado (Laudon)? | Fato bruto antes de ser organizado para uso. |
| Por que "34" não basta? | Falta contexto; sem contexto não é informação. |
| Cadeia do BI? | Dados → Informação → Conhecimento → Decisão → Ação → Resultado. |
| ETL significa? | Extract, Transform, Load. |
| Onde ocorre o Transform? | Na staging area. |
| Técnicas de preparação (ordem)? | Requisitos, Dados disponíveis, Medidas, Dimensões, Visuais. |
| Último passo do processo analítico? | Escolha dos visuais. |
| Dashboard serve para? | Visão resumida, monitorar, identificar exceções. |
| Relatório serve para? | Análise detalhada e investigação. |
| Decisão estratégica pede? | Dashboard agregado. |
| Decisão tática pede? | Dashboard com drill-down. |
| Decisão operacional pede? | Relatório analítico. |
| Foco do relatório analítico? | Precisão e rastreabilidade. |
| Foco do dashboard? | Tendências, KPIs e exceções. |
| 5 passos do Fluxo de Decisão? | Objetivo, Público, Tipo de decisão, Agregação, Visualização. |
| Aspectos importantes da visualização? | Granularidade, carga cognitiva, tempo, frequência, exploração. |
| Inmon? | Top-down, DW corporativo, fonte única da verdade, integridade. |
| Kimball? | Bottom-up, Data Marts dimensionais, fato/dimensão, foco no usuário. |
| Davenport? | Cultura analítica, storytelling, vantagem competitiva. |
| Few? | Design claro, sem sobrecarga, gráfico adequado, consistência. |
| Tufte? | Reduzir ruído visual. |
| Eckerson? | Diferença entre relatório e dashboard. |
| 4 características do DW (Inmon)? | Orientado por assunto, integrado, variante no tempo, não volátil. |
| OLTP é? | Sistema de transações do dia a dia; ruim para análise. |
| Tabela fato guarda? | Medidas numéricas + chaves das dimensões. |
| Tabela dimensão guarda? | Descrições (produto, categoria, data, cliente). |
| PRD exporta para? | PDF, Excel, HTML, CSV. |
| PRD lê de? | JDBC, OLAP (Mondrian), CSV/XML/JSON. |
| Self-Service BI? | Usuário de negócio cria as próprias análises sem depender da TI. |
| Gráfico para tendência? | Linha (série temporal). |
| Gráfico para comparação? | Colunas. |
