# Gestão de Negócios e Sustentabilidade — Flashcards

| Pergunta | Resposta |
|---|---|
| Origem da palavra gestão? | Latim: gerir, gerenciar, administrar. |
| Gestão é combinação de quê? | Técnica, tecnologia, ciência, arte e disciplina. |
| 4 funções da gestão? | Planejar, organizar, liderar, controlar. |
| Eficácia? | Alcançar os objetivos. |
| Eficiência? | Usar bem os recursos para alcançá-los. |
| Técnica? | Know-how: como fazer (prática/experiência). |
| Tecnologia? | Know-how + know-why: como e por que fazer. |
| Ciência? | Conhecimento sistematizado por métodos e pesquisas. |
| Gestão como arte? | Fazer as coisas através das pessoas; liderar é arte. |
| "Outra visão" de gestão? | Disciplina que torna possível o desempenho conjunto. |
| Autor "mais importante das organizações"? | Peter Drucker. |
| Fórmula do valor? | Benefícios ÷ Custos. |
| Custos para o cliente incluem? | Dinheiro, tempo, esforço, aspectos psicológicos. |
| Quem define o valor? | O cliente. |
| Proposição de valor? | Produto/serviço + benefícios + preço justo. |
| Vantagem competitiva? | Criar valor melhor que o concorrente, difícil de imitar. |
| Ideia central de Sun Tzu? | A melhor vitória é a que se consegue sem lutar. |
| Diferenciação × confronto? | Diferenciação pode ser mais inteligente. |
| Sequência da informação? | Dados → Informação → Análise → Decisão. |
| Ciclo de gestão (Sun Tzu)? | Diagnóstico → Planejamento → Estratégia → Execução → Controle → Ajustes. |
| Planejamento trata de quê? | Implicações futuras de decisões presentes. |
| Plano deve ser feito... | "Pela" empresa, não "para" ela. |
| Mais importante: plano ou planejamento? | O planejamento (processo). |
| Estratégia (Maximiano)? | Seleção dos meios para realizar objetivos. |
| Estratégia (Chiavenato)? | Mobilização de todos os recursos, objetivos de longo prazo. |
| Tática? | Esquema específico de recursos dentro de uma estratégia. |
| Strategos? | Generais da Grécia antiga. |
| Frase de Porter? | "Arrume tempo para pensar..." |
| 1ª etapa do planejamento estratégico? | Missão + Visão. |
| Saídas da estratégia? | Objetivos, iniciativas e indicadores estratégicos. |
| Planejamento modifica? | Pessoas, tecnologia e sistemas. |
| SWOT interno? | Forças e Fraquezas. |
| SWOT externo? | Oportunidades e Ameaças. |
| 5 forças de Porter? | Rivais, fornecedores, clientes, novos entrantes, substitutos. |
| 3 dimensões da sustentabilidade? | Econômica, social, ambiental. |
| Tecnologia sem gestão é...? | Apenas custo. |
