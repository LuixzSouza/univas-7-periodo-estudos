## O que é a matéria
Como **gerir** uma empresa: conceito de gestão, **criação de valor** para o cliente, **planejamento estratégico** (onde estamos → onde queremos chegar → como), análise do ambiente (SWOT, Porter) e **sustentabilidade** (econômica, social, ambiental).

## Os pontos que mais importam
1. **Gestão** = realizar os objetivos de forma **eficaz e eficiente** por meio de **planejar, organizar, liderar e controlar**. Gestão é **arte + técnica + tecnologia + ciência + disciplina**. "Gestão é ação."
2. **Técnica** = como fazer (know-how) · **Tecnologia** = como + por que (know-how + know-why) · **Ciência** = conhecimento sistematizado (métodos, teorias) · **Arte** = criatividade, liderar pessoas.
3. **Valor = Benefícios ÷ Custos** (para o cliente). **Quem define o valor é o cliente.** Custos incluem dinheiro, tempo, esforço e aspectos psicológicos.
4. **Proposição de valor** = produto/serviço + benefícios + preço justo ("Por que o cliente escolheria você?"). **Vantagem competitiva** = criar valor melhor que o concorrente com competências **difíceis de imitar**.
5. **Sun Tzu (A Arte da Guerra):** "a melhor vitória é aquela sem lutar" → **diferenciação > confronto**; conheça a si mesmo e o concorrente; escolha onde competir (nicho); momento certo; informação; adaptabilidade; liderança; planejar antes de agir.
6. **Planejamento:** trata das **implicações futuras de decisões presentes**; é **processo contínuo**; o processo vale mais que o plano; plano feito **"pela"** empresa, não **"para"** ela.
7. **Estratégia:** Maximiano = "**seleção dos meios** para realizar objetivos"; Chiavenato = mobilização de todos os recursos, **longo prazo**; **tática** = esquema específico **dentro** da estratégia. Origem grega: *strategos* = generais.
8. **Etapas do planejamento estratégico:** Missão + Visão → Análise dos ambientes → Objetivos → Situação atual → Estratégia → Desdobramento (objetivos, iniciativas, indicadores).
9. **Ferramentas:** **SWOT/FOFA** (interno: Forças/Fraquezas; externo: Oportunidades/Ameaças) e **5 Forças de Porter** (rivais, fornecedores, clientes, novos entrantes, substitutos).
10. **Sustentabilidade = 3 dimensões:** econômica, social, ambiental.

## Como tudo se conecta
```
GESTÃO (planejar, organizar, liderar, controlar)
   └─► para CRIAR VALOR ao cliente (Benefícios ÷ Custos)
          └─► e transformar em VANTAGEM COMPETITIVA
                 └─► via PLANEJAMENTO ESTRATÉGICO
                        (Missão/Visão → SWOT + Porter → Objetivos → Estratégia → Ação)
                        └─► equilibrando ECONÔMICO + SOCIAL + AMBIENTAL (sustentabilidade)
```
