# Gestão da Qualidade — Flashcards

| Pergunta | Resposta |
|---|---|
| Qualidade (ISO 9000)? | Grau em que características inerentes cumprem os requisitos. |
| NBR ISO 8402 fala de quais necessidades? | Explícitas e implícitas. |
| Quem criou o controle estatístico de processo? | Walter Shewhart. |
| TQM no Japão? | Deming e Juran (1950–1970). |
| ISO 9001 surge quando? | Década de 1980. |
| Qualidade de produto? | Características do software entregue. |
| Qualidade de processo? | Como o software é desenvolvido. |
| Qualidade para o cliente? | Prazo, orçamento, escopo, ROI. |
| McCall — ano e cliente? | 1977, Força Aérea dos EUA. |
| 3 grupos de McCall? | Operação, Revisão, Transição do produto. |
| Norma de qualidade mais recente? | ISO 25010. |
| ISO 25010 — 2 modelos? | Qualidade em uso (5) e de produto (8). |
| 8 características de produto? | Adequação funcional, Eficiência de desempenho, Compatibilidade, Usabilidade, Confiabilidade, Segurança, Manutenibilidade, Portabilidade. |
| 5 de qualidade em uso? | Eficácia, Eficiência, Satisfação, Ausência de riscos, Cobertura do contexto. |
| Testabilidade é sub de? | Manutenibilidade. |
| Interoperabilidade é sub de? | Compatibilidade. |
| Heurística 1 de Nielsen? | Visibilidade do status do sistema. |
| Heurística "Ctrl+Z"? | Controle e liberdade do usuário. |
| Prevenção × recuperação de erros? | Evitar antes × ajudar depois. |
| Métrica (IEEE)? | Medida quantitativa do grau em que algo possui um atributo. |
| Direta × indireta? | Contada/observada × calculada de outras. |
| 3 categorias por objeto? | Produto, Processo, Projeto. |
| SOD? | Funções entregues por período (orientada a função). |
| PDR? | Horas para desenvolver uma função (produtividade). |
| Métrica de vaidade? | Número que não indica valor real (ex.: LOC escritas). |
| 4 critérios para escolher métricas? | Relevância, Mensurabilidade, Custo de coleta, Ação. |
| GQM? | Goal → Question → Metric. |
| Modelo de meta de Basili? | Analisar [objeto] com finalidade de [propósito] com respeito a [foco] do ponto de vista de [perspectiva] no contexto de [ambiente]. |
| Quem criou o CMM? | SEI (Software Engineering Institute). |
| 5 níveis do CMM? | Inicial, Repetível, Definido, Gerenciado, Otimizado. |
| Nível em que o sucesso depende de heróis? | 1 – Inicial. |
| Nível com processo padrão da organização? | 3 – Definido. |
| Nível com controle quantitativo? | 4 – Gerenciado. |
| Área-chave do nível 5? | Prevenção de defeitos, mudanças tecnológicas e de processo. |
| Garantia da qualidade é área-chave de qual nível CMM? | Nível 2. |
| Práticas-chave dizem "o quê" ou "como"? | "O quê". |
| Por que surgiu o CMMI? | CMM restrito a software e fragmentado em vários modelos. |
| CMMI por estágios? | Maturidade da organização, níveis 1–5. |
| CMMI contínuo? | Capacidade de cada processo, níveis 0–5. |
| Nível 0 do contínuo? | Incompleto. |
| Verificação? | Atende aos requisitos especificados. |
| Validação? | Atende às necessidades do usuário. |
| 3 atividades do gerenciamento da qualidade? | Planejamento, Garantia, Controle. |
| QA foca em? | Processo (prevenir). |
| QC foca em? | Produto (detectar). |
| Técnica dinâmica de SQA? | Testes. |
| Revisão formal com facilitador treinado e checklist? | Inspeção. |
| Revisão informal liderada pelo autor? | Walkthrough. |
| DMAIC? | Seis Sigma (Definir, Medir, Analisar, Implementar/Melhorar, Controlar). |
| SQA executa testes? | Não (verifica se foram planejados e registrados). |
